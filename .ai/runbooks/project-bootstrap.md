# Runbook: Project Bootstrap For This NixOS System

Updated: 2026-06-13

## Purpose

Give Codex a repeatable first read for this system and keep future projects
organized as they are added.

## Steps

1. Read `AGENTS.md`.
2. Read `.ai/current-state.md`.
3. Read `.ai/handoff.md`.
4. Read `.ai/verification.md`.
5. Read relevant files in `.ai/decisions/` and `.ai/runbooks/`.
6. Check `git status --short --branch`.
7. If the work concerns a new project, add it to `.ai/projects/index.md`.

## Rules

- Keep system memory in the repo, not in chat history.
- Keep future projects separated in the registry.
- Record durable changes and verification together.

## Notes

- This runbook is the starting point for sessions that need the machine's
  current system context before making changes.
